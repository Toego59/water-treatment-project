# Clear by Chemistry
A plain-English website on how chemical processes make water safe to drink.
Open `index.html` in a browser, or enable GitHub Pages (Settings > Pages > main branch) to publish it.

```
water-treatment/
├── index.html                  page structure and text
├── css/styles.css              colours, fonts, layout (edit :root to re-theme)
├── js/main.js                  parallax + interactive tank (edit STEPS to change text)
├── assets/images/              hero-back.svg, hero-mid.svg, hero-front.svg
└── README.md
```
